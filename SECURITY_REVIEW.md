# Проверка перед загрузкой в GitHub

Дата: 2026-09-16. Источник: предоставленный архив `src.zip`.

## Найдено и устранено

- В `dkp/config.php` находились реквизиты БД. Файл исключён из копии для Git.
- В `dkp/config.example.php` находился тот же пароль БД. Пример полностью
  заменён на демонстрационные настройки, включая имя базы и почтовый адрес.
- Вложенный `fix0r-regru.zip` исключён как ненужный архив старой версии.
- Добавлен `.gitignore` для секретов, баз, дампов, архивов и runtime-файлов.

Рекомендация владельцу: сменить переданный пароль БД на хостинге и обновить
рабочий `dkp/config.php`. Эта проверка не меняет пароль на сервере.

## Проверенная область

Проверены имена и содержимое файлов, вложенный ZIP, настройки PHP,
SQL-файл, статические ресурсы, токены распространённых провайдеров,
закрытые ключи, JWT, литералы паролей, высокоэнтропийные строки,
почтовые адреса, числовые идентификаторы, IP и локальные пути.
Дополнительно проверяется отсутствие точных значений найденных рабочих
реквизитов в подготовленных файлах и единственном новом Git-коммите.

Исходный архив не содержал `.git`, баз пользователей или SQL-дампов данных.
`schema.sql` содержит определения таблиц. SQL-запросы INSERT в PHP
являются кодом приложения. Длинное число в проверке ID — предел int64.
Фиксированный парольный хеш в авторизации используется как dummy hash.

Сохранены публичные ссылки и ник автора, адрес публичного TeamSpeak-сервера,
а также сведения об авторах и контакты из лицензии сторонних шрифтов.
Непубличные записи участников в проверенном архиве не обнаружены.

## Границы проверки

Это проверка перед публикацией исходников, а не полный аудит безопасности
приложения. Она не проверяет рабочую БД, хостинг и файлы вне архива и не
гарантирует отсутствие секретов неизвестного формата.

## Проверки подготовленной копии

- PHP: синтаксис всех 11 файлов проверен.
- Рабочие реквизиты БД не встречаются ни в одном подготовленном файле.
- Остальные исходные файлы сайта сохранены байт-в-байт.
- Создана новая история Git без исходного конфига и вложенного ZIP.
