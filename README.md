# Fix0r / FC — сайт сообщества

Текущие исходники главной страницы FC / TrustTheGame и кабинета ДКП.
Главная содержит ссылки на Telegram, YouTube и сервер TeamSpeak 3.
Кабинет включает авторизацию, состав, балансы, события и аукционы.

## Структура

- `index.html`, `style.css`, `typography.css`, `telegram-notice.css`, `app.js` — главная.
- `dkp/` — приложение PHP.
- `dkp/config.example.php` — пример настроек без рабочих реквизитов.
- `dkp/schema.sql` — только первоначальные таблицы авторизации.
- `fonts/LICENSE.txt` — лицензия сторонних шрифтов; сохранять вместе со шрифтами.

## Развёртывание

Используется PHP 8.3 с PDO MySQL и поддержкой Argon2id, MySQL 8 и HTTPS.
Настройте отправку почты средствами хостинга.
На сервере создайте `dkp/config.php` по примеру и укажите свои настройки.
На существующем хостинге сохраняйте рабочий `config.php` при обновлении.
Репозиторий не содержит баз, пользовательских записей и резервных копий.

`dkp/schema.sql` недостаточно для установки полного ДКП с нуля:
приложению нужны таблицы ранее установленных модулей и переноса из бота.
Их миграции не были включены в переданный архив. Не импортируйте дамп
рабочих участников в репозиторий для устранения этого ограничения.

Автозавершение аукционов запускается через Cron каждую минуту:

```sh
/path/to/php /path/to/site/dkp/auction_cron.php
```

Публикуйте на веб-сервер только файлы сайта. Каталог `.git`, этот README
и отчёт проверки не должны находиться в общедоступном корне сайта.

## Секреты

`dkp/config.php`, файлы `.env`, ключи, базы, дампы, архивы и журналы
исключены через `.gitignore`. Пример конфига содержит только заглушки.
`.gitignore` не удаляет файлы, уже добавленные в Git, и не заменяет проверку
состава коммита перед отправкой.
