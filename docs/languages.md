# Русский и английский

Переключатель RU / EN находится сверху, рядом с выбором темы, на главной
и в кабинете ДКП. Начальный язык — русский. `/en/` открывает английскую
главную; `/?lang=ru` явно возвращает русский. Выбор сохраняется на год
в cookie `fc_language` и в localStorage `fc-site-language`.

В ДКП язык определяется сервером: допустимый `?lang=ru|en`, затем cookie,
затем русский. Ссылки переключателя сохраняют раздел, выбранное событие,
аукцион и страницы списков. Формы не отправляются при смене языка;
несохранённые поля нужно сначала сохранить. Время событий остаётся московским
(MSK, UTC+3), а числовые даты — в формате день.месяц.год.

Переведены главная, биография, правила, расписание, подсказки, подписи для
экранных дикторов, состояния фонаря и темы. В ДКП переведены формы входа и
регистрации, профиль, управление, события, аукционы, объявления, настройки
Telegram, ошибки и письма подтверждения/сброса пароля.

Ники, названия событий и предметов, тексты объявлений, комментарии и данные
истории не переводятся автоматически. Сообщения отдельного Telegram-бота
и встроенный интерфейс Twitch управляются соответствующими сервисами.

## Файлы

- `index.html` — русская главная, исходник для сборки.
- `en/index.html` — готовая английская главная. Работает без JavaScript.
- `i18n/en.json` — общий словарь английских переводов.
- `scripts/build-en.py` — сборка английской главной из русского исходника.
- `language.js`, `language.css` — выбор языка, его сохранение и оформление.
- `dkp/i18n.php` — серверный перевод и ссылки переключателя.
- `app.js`, `theme.js` — динамические подписи для обоих языков.

После изменения главной или словаря запустите:

```sh
python3 scripts/build-en.py
php tests/i18n.php
```

Сборка останавливается, если у русского текста на главной нет перевода.
Функцию `t()` используйте только для текста интерфейса, а не пользовательских
данных. Экранируйте результат в HTML через `h()`.

## Обновление Reg.ru

Обновление GitHub само по себе не меняет хостинг.
Загрузите файлы главной, каталоги `en/`, `i18n/`, `fonts/`, а также изменённые
PHP-файлы и `.htaccess` из `dkp/`. Сохраняйте структуру каталогов. ДКП теперь
зависит от `dkp/i18n.php` и `i18n/en.json` — загрузите их до остальных PHP.

Существующие `dkp/config.php`, `dkp/telegram_config.php`, `dkp/cw_schedule.php`
и базу данных сохраняйте. Миграций базы для этого обновления нет.
Не загружайте в публичный корень `tests/`, `scripts/`, `docs/` и `.git`.

Проверены локально: RU/EN и возврат, сохранение выбора, переход в ДКП,
обе темы, фонарь, вкладки интересов, якорь стрима и экраны 320–1440 px.
Twitch был изолирован во время проверки вёрстки; реальное воспроизведение
не проверялось. Проверки PHP используют локальные фикстуры и SQLite,
не рабочую базу и почту хостинга.
