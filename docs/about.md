# Раздел «О себе»

На главной, после плеера Twitch, расположен раздел `#about`. Ссылка «О себе»
в шапке видна и на телефонах.

Раздел содержит отредактированную историю, предоставленную владельцем сайта:
образование программиста, путь в PUBG, квалификацию PGI, перерыв в 2019 году,
возвращение и следующий этап в Apex. Сохранены команды, приглашения,
благодарность зрителям и ссылки на Twitch/Telegram.

Результаты разделены по играм:

- Apex: топ-3 GLL Community Cup #42; топ-1 первого и топ-2 второго раундов
  квалификации ALGS.
- PUBG: топ-100 RU / топ-500 EU FACEIT и 19 пунктов турнирного опыта.
  Период 2017–2018 относится только к PUBG. Квалификации обозначены как
  участие, а не победы в основных турнирах.

История команд и полный список турниров раскрываются через нативный `details`:
работают с клавиатуры и без JavaScript. Смена темы сохраняет раскрытые блоки.
Цвета берутся из палитры сайта; поддерживаются обе темы. Новых внешних
виджетов или запросов к API раздел не добавляет.

## Установка

1. Сохраните копию текущего корневого `index.html`.
2. Загрузите `about.css` в `www/fix0r.ru/`.
3. Замените `www/fix0r.ru/index.html` обновлённым файлом.
4. Нажмите Ctrl+F5 и откройте «О себе». Проверьте раскрытие истории и турниров.

Всего два файла сайта. Обновление рассчитано на текущую главную с двумя
темами. SQL, изменения конфигурации и Cron не требуются. `docs/`, README
и снимки проверки на хостинг загружать не нужно.

Текст и результаты редактируются в секции `#about` файла `index.html`,
оформление — в `about.css`. При изменении списка турниров обновляйте число
в `.about-count`. Данные биографии предоставлены владельцем; внешняя
проверка турнирных результатов в рамках этого обновления не проводилась.
