Объявления гильдии — v4.6

Установка поверх v4.5.2:
1. Сохрани резервную копию базы и папки dkp.
2. В phpMyAdmin выбери базу сайта и импортируй private/01-announcements.sql.
   Создаются 3 пустые таблицы; повторный импорт безопасен.
3. Загрузи все 7 файлов из папки dkp в www/fix0r.ru/dkp с заменой:
   index.php, profile_overview.php, style.css, .htaccess,
   announcements_store.php, announcements_view.php, announcement_banner.php.
   Последние три файла — новые. Убедись, что .htaccess тоже загружен.
   config.php, auth.php и Cron не меняй. private и tests на сайт не загружай.
4. Обнови кабинет (Ctrl+F5). Открой «Объявления гильдии» → «Новое объявление».
5. Опубликуй тестовое объявление, закрепи его, включи подтверждение.
   Проверь показ в кабинете и отметку «Прочитал» с аккаунта участника.

Возможности:
- Публиковать, редактировать, закреплять и удалять из показа может администратор.
- Читают офицеры, администратор и аккаунты, связанные с активными участниками ДКП.
- Кнопка подтверждения доступна только владельцу активного связанного профиля.
- Заголовок — до 120 символов; текст — до 2000, с переносами строк.
  HTML не исполняется. Ссылки в тексте отображаются обычным текстом.
- Одно закреплённое объявление показано компактно над слайдером в кабинете.
  Полный текст раскрывается нажатием; подтверждение — на странице объявления.
  Закрепление нового объявления снимает закрепление предыдущего.
- Необязательный срок показа задаётся по Москве. После его окончания объявление
  скрывается у участников, оставаясь в административном архиве. Cron не нужен.
- В ленте по 20 публикаций с переходом между страницами; администратор видит также
  удалённые и просроченные записи с соответствующими пометками.
- «Прочитал» сохраняет отметку пользователя для текущей версии объявления.
  Простое открытие страницы НЕ считается подтверждением.
- Администратору доступен список «Прочитали N из M» по ТЕКУЩЕМУ активному составу.
  Участники без аккаунта помечаются отдельно и входят в общее число.
  Новые участники включаются, удалённые из состава исключаются.
- При редактировании по умолчанию включён запрос повторного прочтения. Для опечатки
  можно снять эту галочку и сохранить прежние подтверждения. При первом включении
  требования прочтения начинается новый набор подтверждений автоматически.
- Удаление скрывает публикацию, сохраняя запись, подтверждения и журнал действий.
  Старые версии подтверждений и изменения сохраняются в базе.
- Повтор запроса не создаёт дубликаты. Устаревшие формы редактирования и прочтения
  отклоняются; после изменения текста его нужно перечитать.

Защита:
Права и актуальная сессия проверяются на сервере; POST защищён CSRF.
Публикации, закрепление, отметки и журнал записываются транзакционно под общей
блокировкой ДКП. При ошибке журнала вся операция откатывается.
Для длинных русских текстов предел тела запроса увеличен с 8 до 32 КиБ в PHP
и .htaccess. Ограничения частоты запросов сохранены. Почтовой/Telegram-рассылки нет.

Проверено: PHP 8.3, 50 проверок SQLite; HTTP-вход администратора, публикация,
отказ при неверном CSRF, закрытие раздела для гостя, подтверждение участником.
MySQL-импорт и обработку .htaccess нужно проверить на хостинге.
Браузерная визуальная проверка недоступна в среде подготовки.
Разработчику: php -d extension=pdo_sqlite tests/announcements.php
