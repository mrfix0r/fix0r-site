# Компактная навигация кабинета

Вместо пяти отдельных кнопок вертикальным списком отображается общая полоса
«Объявления / События / Аукционы». Кнопки оформлены в зелёной палитре с отдельными контурами.
Общая зелёная подсветка плавно перемещается к кнопке под курсором
или в фокусе клавиатуры; после ухода возвращается к объявлениям.
Наведение не открывает раздел — переход происходит только по нажатию.
На сенсорном экране наведение не требуется. При системной настройке
уменьшения движения подсветка переключается без анимации.
Используется CSS; в браузерах без поддержки :has сохраняется обычная подсветка кнопок.
На самых узких экранах до 360 px объявления занимают первую строку,
события и аукционы — вторую. Высота каждого перехода — не менее 44 px.

У офицера и администратора ниже находится раскрывающийся пункт «Управление»:

- офицер видит «Управление ДКП»;
- администратор — «Управление ДКП» и «Статистика сайта»;
- участнику этот пункт не показывается.

Меню по умолчанию закрыто; раскрывается кликом, Enter или пробелом.
Работает без JavaScript. Ссылки, серверные проверки прав и учёт кликов
сохранены. Ближайшее событие/аукцион и блок важных объявлений не меняются.

## Установка

Сохраните копии заменяемых файлов. Загрузите содержимое `site/` из архива
в `www/fix0r.ru/`, сохраняя вложенные папки:

1. `dkp/profile-navigation.css` — новый файл.
2. `i18n/en.json` — перевод короткого названия «Аукционы».
3. `dkp/profile_overview.php` и `dkp/index.php` — с заменой.

Всего четыре файла сайта. SQL, `config.php`, `auth.php` и Cron менять не нужно.
Документацию и `INSTALL.txt` на хостинг не загружайте.
Обновите кабинет через Ctrl+F5.

## Проверка

Проверены PHP-синтаксис, три роли, RU/EN, обе темы, ширины 320/390/1440 px,
переходы с клавиатуры, работа раскрытия без JavaScript и события статистики.
Дополнительно проверены движение подсветки при наведении, возврат после ухода
курсора, положение под кнопкой в двухстрочной вёрстке и отключение анимации
при `prefers-reduced-motion`.
На ширине 390 px закрытая навигация администратора занимает 104 px вместо
280 px — на 63% меньше. Открытое меню расширяется по содержимому.
