Сортировка состава ДКП — v4.3.1

Установка поверх v4.3 (обновления с удалением участников):
Сохрани копию dkp/manage_view.php и замени его файлом из архива.
SQL и изменение Cron не нужны.

В «Управление ДКП» нажми заголовок «Связана», «Всего», «В ставках»
или «Доступно». Первое нажатие сортирует по возрастанию, повторное —
по убыванию. Стрелка показывает текущий порядок.
Для «Связана»: по возрастанию сначала Нет, по убыванию сначала Да.
Числа сравниваются численно. Равные значения сохраняют порядок по нику.
Сортировка перезагружает страницу: применяй её перед заполнением формы
начисления, поскольку несохранённые отметки и поля будут сброшены.

Проверены PHP-синтаксис и вывод всех восьми вариантов сортировки.
