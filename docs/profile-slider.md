Компактный слайдер кабинета — v4.5.2

Установка поверх v4.5.1:
1. Сохрани копию текущих файлов.
2. Замени в www/fix0r.ru/dkp три файла из dkp этого архива:
   index.php, profile_overview.php, style.css.
3. Обнови страницу. При необходимости нажми Ctrl+F5.
SQL, настройки подключения и Cron менять не нужно.

Вместо двух карточек подряд отображается одна. Переключатели «Событие» и
«Аукцион» расположены над ней; выбранный выделен цветом. По умолчанию — событие.
Скрытая карточка не занимает места, высота подстраивается под выбранную.
Переключение без перезагрузки и без автопрокрутки, с короткой анимацией появления.
Работает мышью, касанием и клавиатурой: Tab на переключатель, затем стрелки.
JavaScript не используется, политика безопасности сайта сохранена.
При системной настройке уменьшения движения анимация отключена.
После обновления страницы снова выбирается «Событие».

Логика выбора ближайшего события и аукциона не меняется.
Проверены PHP-синтаксис и структура двух взаимоисключающих переключателей.
Браузерный визуальный тест в среде подготовки недоступен; после загрузки
проверь переключение и отображение на телефоне.
